Storage

Your notes are one plain Markdown file. You can keep it anywhere.

Notes file

The TUCK_NOTES_DIR environment variable overrides this folder for this run.

Tip: choose a folder inside your Obsidian vault to see notes there, or a OneDrive / Dropbox / iCloud Drive folder to sync them between computers. Tuck has no cloud of its own.

BackupsBefore Tuck changes the file (edit, delete, move) it saves a copy here. The newest 20 are kept. Tuck never deletes your notes file.

Privacy

Tuck only sees Ctrl and C. It never sends your notes anywhere. It does not record other keys. Your notes stay in your file, and the log never contains note text or window titles.
Accessibility accessmacOS needs this so Tuck can notice ⌘C. Tuck never reads other keys.
Never capture in these appsCopies made in these programs are ignored, for example password managers.
Never capture when the window title containsMatched without regard to case, for example "bank" also matches "Online Banking".
Daily reminderA notification with one of your past notes, once a day.
Check for updates automaticallyThe only feature that uses the network. Off by default. When on, Tuck checks GitHub Releases for a newer version.
