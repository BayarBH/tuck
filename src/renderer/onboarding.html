Tuck

Copy it twice. It's tucked away.

Tuck saves what you copy into a Markdown notebook, without pulling you out of what you're reading.

Ctrl+CC
Double-tap to save the selection
Ctrl+C
Hold to save it with a thought

Private by design: Tuck only notices the timing of Ctrl and C, never connects to the internet unless you turn on update checks, and keeps your notes in a plain file on this PC.

Allow Tuck to notice ⌘C

macOS asks you to allow Accessibility access so Tuck can notice ⌘C; it never reads other keys.

  1. Click Grant access.
  2. In System Settings, turn on Tuck under Privacy & Security › Accessibility.
  3. Come back here. This page updates by itself.

Later macOS may also ask whether Tuck can control “System Events”: that lets Tuck skip private windows by title and return focus after a thought.
