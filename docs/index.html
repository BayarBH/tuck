Tuck away the lines worth keeping.

Reading an article or an AI answer and a sentence stops you? Press Ctrl+C twice (⌘C on a Mac). Tuck slips it into a Markdown notebook and you keep reading. No window, no click, no lost flow.

Tuck sees only Ctrl and C (⌘ and C on a Mac).
Nothing leaves your computer.

  • No keylogging. The keyboard hook reduces every key to "Ctrl", "C" or "something else" and its timing. Keys are never stored or logged.
  • Clipboard only when you ask. Tuck reads the clipboard only after a double tap or a hold. One Ctrl+C is just a copy.
  • Skips sensitive apps. Password managers and windows titled like "bank", "password" or "login" are excluded by default. You can edit the list.
  • No network. No account, no analytics, no crash uploads. Update checks are off until you turn them on, and then only talk to GitHub.

Questions

Why does Windows warn about the installer?

Signing certificates cost money every year and new ones still need time to earn SmartScreen reputation. Until Tuck is signed, Windows shows a warning for downloaded installers it has not seen often. The source code is public, and you can build the installer yourself with npm run dist.

My antivirus (Defender, 360, Huorong) flags Tuck. Is it a keylogger?

Tuck uses a global keyboard hook, the same mechanism keyloggers use, so heuristic scanners sometimes flag it. Tuck only looks at Ctrl and C timing and has no network code apart from the optional update check. If your antivirus blocks it, allow Tuck.exe or report the false positive to the vendor; we report them too.

It doesn't capture in some windows.

Windows does not let a normal app see keys pressed in a program running as administrator (for example an elevated terminal). Copy from there works as usual, it just isn't captured. Excluded apps (password managers, banking pages) are skipped on purpose.

Does it work with several monitors and high-DPI screens?

Yes. The bar appears on the monitor where your mouse is, sized for that screen's scaling.

Where are my notes, and can I sync them?

By default in Documents\Tuck\tuck.md. Choose another folder in Settings, such as an Obsidian vault, OneDrive or Dropbox. Tuck keeps automatic backups before edits.

Is there a Mac version?

Yes, as a beta. Use ⌘C instead of Ctrl+C; Tuck lives in the menu bar. macOS asks you to allow Accessibility access once, which Tuck uses only to notice ⌘C. While a password field or Secure Keyboard Entry (for example in Terminal) is active, macOS hides keys from Tuck, so nothing is captured there. The beta has not been tested on real hardware yet; reports are welcome.

How do I report a bug?

Tray menu → Report a problem… opens a prefilled GitHub issue in your browser after you confirm. It contains version numbers only, never your notes. Or open an issue on GitHub directly.
